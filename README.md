This repository contains AlphaFold PDB files for MLRR1_PLAF7 protein from Plasmodium falciparum which is a hypothetical protein ~10000 aa long. 
Protein length is approx ~10,000 residues and does not have any crystallographic or full-length predicted models. 
This is an attempt to model the full structure, N-terminal to C-terminal in small chunks or chains. The sequence overlaps at the terminals by 200 residues. A total of 7 structures have been predicted here. Delete those repetitive residues and concatenate using the UCSF-Chimera or Pymol. Ample spaghetti regions can be observed between the secondary structures. It might reduce the structure prediction confidence score, but is still reliable for use.
